# Frontend Bibliotheque DIT

Application React (Vite + TypeScript) pour le catalogue, les emprunts et les recommandations.

## Variables d'environnement

Copier `.env.example` vers `.env`. Seules les variables prefixees `VITE_` sont exposees au bundle.

## Scripts

- `npm run dev` — serveur de developpement
- `npm run build` — build de production
- `npm run preview` — previsualisation du build
- `npm run lint` — verification TypeScript

## Stack

- React 19
- React Router
- TanStack Query
- Zod (validation a etendre sur les formulaires)
